# Elliot Garamendi CV

CV y portafolio personal construido con **HTML**, **CSS** y **JavaScript vanilla**.
El contenido dinámico (experiencia, proyectos, skills y logros) se carga desde `https://elliotgaramendi.github.io/api/json/cv.json`.

## Demo

- Producción: [elliotgaramendi.github.io/elliotgaramendi-cv](https://elliotgaramendi.github.io/elliotgaramendi-cv/)

## Quick Start

1. Instala VSC y la extensión **Live Server**.
2. Abre el proyecto con VSC.
3. Ejecuta **Open with Live Server** en `index.html`.

Luego abre: [http://localhost:3000](http://localhost:3000)

## Features

- Perfil profesional con enfoque frontend + AI.
- Secciones dinámicas renderizadas desde JSON.
- Sanitización básica en JS para evitar inyección de HTML.
- Botón para descargar/imprimir CV en PDF (`window.print()`).
- Diseño responsive con utilidades CSS propias.
